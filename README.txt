# KrishiFlow v2 — Cinematic Website Prototype

This is a no-framework HTML/CSS/JavaScript prototype designed for a beginner-friendly hackathon workflow.

## Open it
1. Extract the ZIP.
2. Open the folder in VS Code using **File → Open Folder**.
3. Open `index.html`.
4. Right-click → **Open with Live Server**.

## What is included
- Cinematic hero scene with a single animated wheat plant (CSS/SVG)
- Animated rain, clouds, particles and slow ambient motion
- Produce-entry screen
- Weather/humidity risk scene
- Market-reference comparison
- Decision engine with SELL / STORE / PROCESS / ATTENTION
- Storage recommendation scene
- Responsive layout

## Prototype note
The weather, market and storage values are **demo data** for the hackathon prototype. Replace them with researched/live sources when your team is ready.
